# add-comment-system

## Why

当前项目已有点赞、收藏、关注和 Feed，但没有评论能力。评论是内容社区的核心互动闭环，也会为推荐、热度、搜索和对账提供重要行为信号。

## What

- 新增二级评论系统：一级评论 + 二级回复，不做无限楼中楼。
- 评论发布采用完全异步写入：接口返回 `202 Accepted` 和 `pendingCommentId`。
- 评论正文写入 Cassandra，评论元数据写入 MySQL。
- 评论/回复支持软删，删除后保留楼层结构。
- 评论点赞复用并扩展当前计数系统，支持 `comment` 实体。
- 评论数、回复数、评论点赞数通过事件异步维护，并由对账服务补偿。

## Impact

- 新增评论元数据表、评论状态查询接口和评论分页接口。
- 新增 Kafka 评论写入主题、批量消费者、失败重试和死信处理。
- 需要扩展计数 Schema 支持评论数和评论点赞。
- 推荐系统将消费评论行为作为反馈事件。

## Non-goals

- 不做无限嵌套评论。
- 不做图片评论。
- 不做评论审核流和敏感词系统。
- 不引入 RabbitMQ/RocketMQ，复用 Kafka。
